# Harborlight Coffee – Café Website
A vintage-themed static website for a fictional Sri Lankan coffee shop, built with HTML, CSS, and JavaScript.

## Features
Hero section with a floating card and a "Today's Special" button powered by JavaScript
Image gallery showcasing the café atmosphere and drinks
Our Story section with ordered list of café values
Weekly Highlights menu table with item names and LKR pricing
Contact section with email link and address
Smooth single-page navigation with anchor links

## Tech Stack
HTML5
CSS3 (Flexbox, Grid, custom animations)
Vanilla JavaScript (DOM manipulation, event listeners)
Google Fonts – Playfair Display & Inter
